# 学术内容与页面文本

## 先建立证据对应关系

阅读原始论文、报告、数据或旧PPT，记录支撑主要结论的章节、图表、公式与实验条件。不要仅根据旧PPT标题扩写出新的科学机制。

对重要陈述区分：原文结论、图表/公式证据、代码或仿真结果、基于上下文的推断、后续建议。优先用简短可见来源，如“来源：原报告第15页”“来源：Fig. 4，Methods”；完整引用和解释可放入备注。无法获得准确定位时说明可核实的位置，不编造页号。

## 按报告类型安排内容

这些是组织参考，不是每次必须出现的章节清单。

- 文献汇报：文献信息 → 背景与核心问题 → 方法与模型 → 实验条件 → 关键图表解读 → 贡献和局限 → 与用户课题的关系。
- 组会进展：研究目标与已有基础 → 本阶段做了什么 → 设置与对比结果 → 问题与可能解释 → 下一步实验和待讨论事项。
- 开题：背景和研究缺口 → 研究问题 → 拟用方法与技术路线 → 可行性依据 → 工作安排和风险。
- 中期/答辩：研究问题 → 方法与贡献 → 实验/仿真证据 → 比较和讨论 → 局限与展望。按研究内容展开，不均分每个章节的页数。

## 高信息密度的写法

用户习惯把大部分要讲的内容放在PPT中。先写出完整、可信的解释，再以短段落和局部小标题组织；不要套用“每页只能几行”或“每条只能几个词”的规则。

- 背景：解释现有方法的不足、它影响什么、当前研究具体解决什么。
- 方法：写清思路、关键步骤、输入输出；公式旁给出变量含义、单位及必要假设。
- 设置：保留观测变量、数据、采样、参数、基线、训练阶段和评价指标等影响结论的条件。
- 结果：解释“图上发生了什么变化”“与什么比较”“支持什么结论”“边界在哪里”。数字只按原始精度或清楚的展示精度使用。
- 贡献：区分作者声称的创新与证据真正支持的贡献；明确是方法、理论、实验还是应用贡献。
- 局限与计划：已验证事实、推断原因和拟开展工作分别陈述，不把计划写成成果。

每页可以包含多个相关证据单元，但围绕一个清楚的研究问题。连续正文保持语义连贯，不将句子拆成大量互不相连的小文本框。必要的限定条件应留在可见页面，备注用于补充讲稿和来源。

## 语言

默认中文；用户指定英文时，标题、正文、图表标签和备注保持英语一致。论文原题、模型名、变量、软件名和参考文献可保留英文。避免宣传式标题和无依据的“显著提升”“充分证明”。只做观察比较时，不写成已经验证因果机制。

## 交稿前逐页核对

标题是否忠实概括内容？正文是否给出理解图表所需的条件？图表数值与来源是否一致？是否混淆相对误差、百分点或百分比变化？来源中的冲突应说明或通过原始材料解决，不自行补全。
